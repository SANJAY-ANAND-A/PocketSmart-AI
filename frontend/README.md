# PocketSmart AI - Frontend

React + TypeScript + Vite web client for PocketSmart AI.

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

3. **Build Production Assets:**
   ```bash
   npm run build
   ```
